抵达体验

Echora 将发现、AI 编排、播放与声音能力组织在同一套音乐体验中。

01 · 发现

跨平台内容，归于一致的发现体验

每日推荐、新歌、热歌、精选与榜单集中呈现，搜索与播放保持统一，平台差异不再打断浏览路径。

  • 跨平台聚合与统一搜索
  • 层次清晰的精选与榜单
  • 单一平台异常时保留其他来源
02 · 音乐场

让聆听意图成为可编辑的编排

音乐场结合当前队列与偏好生成编排提案。结果可预览、可调整、可撤销，最终选择始终由你决定。

  • 对话与编排视图协同
  • 顺序、能量与取舍自由调整
  • EchoraAI、自定义 AI 与本地编排
03 · 播放与声音

围绕聆听，组织每一项播放能力

播放队列、歌词、音质与声音空间围绕当前歌曲展开；已下载内容优先从设备读取，在线播放按可用来源自动选择。

  • 连续的队列、歌词与播放状态
  • 音质回退与多来源播放保障
  • 设备下载、缓存与声音调节
04 · 桌面应用

为长时间聆听而设计的桌面体验

桌面应用兼顾内容浏览、精细编排与系统媒体能力，并支持本地音乐、设备下载和离线播放。

  • 面向桌面的高效导航与多任务布局
  • 系统媒体控制与原生快捷操作
  • 本地音乐、下载与离线播放
05 · 移动应用

围绕触控与移动场景重新组织

独立导航、手势操作与横竖屏布局适配不同握持方式，并连接系统媒体控制与设备下载能力。

  • 触控优先的发现、播放与资料库
  • 系统媒体控制与快捷入口
  • 横竖屏布局、离线播放与设备下载
06 · Web

在浏览器中获得完整的 Echora 体验

无需安装即可使用发现、播放、账户与 AI 能力。界面会根据桌面或移动设备呈现合适的布局。

  • 即开即用的完整核心体验
  • 适配桌面与移动浏览器
  • 始终使用当前在线版本

安装

完成安装与首次打开

各平台保留必要步骤；测试构建会明确标注额外处理。

  1. 01
    拖移至“应用程序”

    打开 DMG，将 Echora 拖入 Applications 文件夹。

  2. 02
    从“应用程序”打开

    正式签名版本可直接启动；当前测试构建可能被 macOS 拦截。

  3. 03
    仅在测试构建被拦截时

    确认安装包来自 Echora 官方 Release 后，在“终端”执行以下命令。

    xattr -rd com.apple.quarantine /Applications/Echora.app
    此步骤会移除该应用的隔离标记，不适用于来源不明的安装包。
  1. 01
    运行安装程序

    优先选择 EXE；需要企业部署时可使用 MSI。

  2. 02
    确认系统提示

    当前测试构建尚未完成代码签名，Windows 可能显示信誉提示。

  3. 03
    从开始菜单打开

    安装完成后，Echora 会保留本机下载与本地音乐。

  1. 01
    下载安装包

    下载 GitHub Release 提供的通用 APK。

  2. 02
    允许本次安装

    系统询问时，仅为当前浏览器或文件管理器授予安装权限。

  3. 03
    完成后关闭授权

    安装完成即可打开 Echora，无需持续保留未知来源安装权限。

隐私建立在清晰的数据边界之上

Echora 分别处理账户内容、设备内容与服务请求，并仅在提供相应功能所需的范围内使用数据。

01账户内容

歌单、收藏、设置、会话与长期偏好由 Echora Cloud 保存，用于维持跨端一致性。

随账户管理
02设备内容

下载、本地音乐、外部文件夹与播放缓存由当前设备独立管理，不进入账户。

保留在设备
03服务请求

搜索、播放解析与 AI 请求仅包含完成当前操作所需的信息，并按服务目的处理。

最小必要范围

服务处理方式

不同能力遵循各自的数据路径。在线音乐无需登录；EchoraAI 与账户能力在登录后提供。

在线音乐
设备直连音乐来源

Echora Cloud 完成目录检索与播放地址解析，音乐内容由设备直接连接相应来源，不经 Cloudflare 中转。

EchoraAI
连接正式 AI 服务商

Echora Cloud 仅完成鉴权与安全转发，将请求直接交付所配置的正式服务商；不改写内容，也不附加与当前编排无关的处理。

自定义 AI
遵循所选服务配置

供应商、模型与密钥随账户安全保存，请求由对应服务商依照其隐私政策和服务条款处理。

本地内容
由设备独立管理

缓存、下载与本地文件的管理只作用于当前设备，不改变账户中的歌单、收藏与会话。

用户控制

账户与设备拥有独立、明确的管理边界

账户安全

显示名称、密码、登录设备与账户状态统一在用户中心管理。

设备空间

缓存与下载可在应用内单独清理，不影响账户保存的内容。

删除保护

账户删除提供 7 天撤销期，期满后再执行数据删除。
